# Описание проекта

## Хранение данных

Вместо SQLite используется обычный JSON-файл `shop_data.json`.
Он содержит три раздела: `clients`, `products`, `orders`.

## ООП

`Client`, `Product` и `Order` — основные классы предметной области.

`CustomerEntity`, `OrderEntity` и `ProductEntity` наследуются от `BaseEntity`.
Общий метод `describe()` демонстрирует полиморфизм.

## GUI

Tkinter используется для форм, таблиц, поиска, сортировки, создания заказов,
импорта и экспорта.

## Аналитика

`matplotlib` используется для двух графиков, `networkx` — для графа связей клиентов.

## Регулярные выражения

`EMAIL_RE` проверяет email, `PHONE_RE` проверяет телефон.

## Обработка ошибок

Операции интерфейса, импорт, экспорт и создание заказа обрабатываются через
`try/except`.

## Python 3.9

В коде не используются конструкции, появившиеся после Python 3.9.
Типы записаны в совместимом стиле.
