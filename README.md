# Система учёта заказов интернет-магазина

Готовый учебный проект по требованиям итоговой аттестации Python.

## Главное

**SQLite не используется.** Постоянное хранение выполняется в `shop_data.json`.

Проект рассчитан на **Python 3.9+**.

## Что реализовано

- классы клиентов, товаров и заказов;
- инкапсуляция, наследование и полиморфизм;
- JSON-хранилище между запусками;
- GUI на Tkinter;
- регистрация клиентов;
- создание заказов и связанных товаров;
- поиск и сортировка;
- импорт CSV;
- экспорт CSV и JSON;
- регулярные выражения для email и телефона;
- обработка ошибок `try/except`;
- собственная сортировка с `lambda`;
- TOP-5 клиентов;
- динамика заказов;
- граф связей клиентов по общим товарам;
- unit-тесты;
- документация.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить:

```bash
python main.py
```

При первом запуске автоматически появится `shop_data.json`.

## Проверка

```bash
python -m unittest discover -s tests -v
```
